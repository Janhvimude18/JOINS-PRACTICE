# Joins Practice – Airline Management Database

This project is part of my internship SQL practice, focusing on mastering different types of **SQL JOIN operations** using **MySQL Workbench**.

## 📌 Project Overview

The database simulates an **Airline Management System** with the following entities:

* **Airlines**: Airline companies and their country of origin.
* **Flights**: Flight details including source, destination, and timings.
* **Passengers**: Passenger personal details and passport numbers.
* **Bookings**: Booking information connecting passengers to flights.

## 🛠️ SQL Concepts Practiced

* **INNER JOIN** → Fetch only matching records from multiple tables.
* **LEFT JOIN** → Retrieve all records from the left table and matching ones from the right.
* **RIGHT JOIN** → Retrieve all records from the right table and matching ones from the left.
* **FULL OUTER JOIN** → Retrieve all records from both tables (simulated with `UNION` in MySQL).

## 📂 Files Included

* `airline_schema.sql` → Script to create tables and insert sample data.
* `join_queries.sql` → Practice queries for INNER, LEFT, RIGHT, and FULL JOIN.
* `outputs/` → Screenshots or results of executed queries in MySQL Workbench.

## 🚀 How to Run

1. Open **MySQL Workbench**.
2. Run `airline_schema.sql` to create the database and insert sample data.
3. Execute queries from `join_queries.sql`.
4. Check results for better understanding of JOIN operations.

## 🎯 Learning Outcome

This project demonstrates how different **SQL JOINS** work in real-world scenarios like **airline management systems**. It improved my understanding of **relational database concepts, data linking, and query optimization**.
